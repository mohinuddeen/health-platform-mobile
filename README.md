# Health Platform Mobile

A healthcare service booking mobile application built with React Native and Expo.

## 📱 Android APK

Download the latest Android APK:

**[Download Health Platform Mobile v1.0.0](../../releases/latest)**

## Features

- User authentication
- Browse healthcare services
- Category-based service filtering
- Service details
- Packages
- Service booking
- Address management
- Family members
- Booking management
- Search
- User profile
- REST API integration

## Tech Stack

- React Native
- Expo
- Expo Router
- TypeScript
- React Query
- Redux
- Axios
- Django REST API
- PostgreSQL / Supabase

## Backend

Django REST Framework API powering authentication, services, bookings, profiles and related functionality.
